# M&H — пародийный интернет-магазин

Демо-проект: полноценный интернет-магазин в виде SPA на чистых HTML, CSS и JavaScript. Пародия на известный бренд одежды: «Это не H&M. Это M&H».

**Демо:** https://adelbashiroff.github.io/mh-store/

## Что умеет магазин

- каталог из 20 товаров, поиск с подсказками, фильтры (категория, цена, размер, цвет, скидка), сортировка, «показать ещё»
- карточка товара: выбор цвета и размера, галерея (вид спереди, «сзади», деталь), отзывы с оценкой, подбор размера
- быстрый просмотр и добавление в корзину прямо из каталога
- корзина: количество, удаление, промокоды, прогресс до бесплатной доставки
- избранное, история заказов, статус заказа в реальном времени
- оформление заказа: валидация полей, доставка (курьер, пункт выдачи, сосед), оплата (карта с проверкой по Луну, при получении, комплиментом)
- хранение корзины, избранного и заказов в `localStorage`
- адаптив, доступность с клавиатуры, hash-роутинг без перезагрузки

## Фишки

- кнопка «Отзеркалить сайт» и логотип, у которого при наведении меняются буквы
- вся одежда нарисована кодом (SVG), никаких картинок
- подбор размера, который всегда выдаёт «H»
- распродажа, которая заканчивается и тут же начинается снова
- промокоды: `ЗЕРКАЛО`, `НАСПУТАЛИ`, `МИНУС500`; код `H&M` магазин отвергает
- cookie-баннер с убегающей кнопкой «Нет, спасибо»

## Запуск

Сборки нет. Открыть `index.html` или поднять любой статический сервер:

```bash
python3 -m http.server
```

## Структура

- `index.html` — каркас страницы
- `style.css` — стили
- `data.js` — каталог, промокоды, доставка
- `art.js` — рисование товаров в SVG
- `app.js` — роутер, корзина, оформление заказа

Это учебный проект-пародия. Не связан с реальными компаниями, все товары, цены и отзывы вымышлены, деньги не списываются.
